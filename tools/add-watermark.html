How to Use:

1. Upload: Select or drag an image into the upload area.

4. Position: Select one of nine watermark positions.

Helpful Tips

Create clean watermarks.

Tip 1: Use a transparent PNG for logos.

Tip 2: Keep opacity moderate for a subtle watermark.

Tip 3: Use Repeat Pattern when stronger protection is needed.

Tip 4: Use Shadow when the watermark is difficult to read against the image.

FAQ

Common questions.

Can I add my own logo?
Yes, choose Logo / Image and upload it.

Can I change transparency?
Yes, use the Opacity control.

Can I repeat the watermark?
Yes, enable Repeat Pattern.

Can I rotate it?
Yes, from -180° to +180°.

Does the original image change?
No.
