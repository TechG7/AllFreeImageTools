How to Use:

1. Upload Image: Select the image you want to watermark.

2. Choose Type: Select Text Watermark to add text or Logo / Image to add your own logo.

3. Set Position: Choose where the watermark should appear.

4. Adjust Size: Increase or decrease watermark size using the Size slider.

5. Opacity: Lower opacity for a subtle watermark.

6. Rotation: Rotate the watermark from -180° to +180°.

7. Repeat Pattern: Enable it to place the watermark repeatedly across the image.

8. Download: Choose your output format and click Add Watermark & Download.

Helpful Tips

Create a clean watermark.

Tip 1: Use a transparent PNG logo for the cleanest logo watermark.

Tip 2: Around 30–70% opacity often works well for subtle branding.

Tip 3: Use Repeat Pattern when you want stronger protection against unauthorized reuse.

Tip 4: Avoid making the watermark so large that it hides important image content.

FAQ

Common questions.

Can I add my own logo?
Yes. Select Logo / Image and upload your logo.

Can I change watermark transparency?
Yes. Use the Opacity slider.

Can I put a watermark in the center?
Yes. Select Center.

Can I repeat the watermark?
Yes. Enable Repeat Pattern.

Does this modify my original image?
No. A new watermarked image is created.

Are my images uploaded?
No server upload is required for processing.
