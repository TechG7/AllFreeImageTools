About Image Color Picker

Find exact colors from photographs, graphics and designs.

Image Color Picker lets you inspect the color of individual pixels in an image.

This is useful for designers, developers, artists and anyone who needs an exact color value from an existing image.

The tool supports four common color formats: HEX, RGB, HSL and HSV.
