How to Use:

1. Upload: Select your JPG, PNG or WEBP image.

2. Select Area: Drag across the image to create a crop selection.

3. Aspect Ratio: Choose Free for any shape or select a preset such as 1:1, 4:3 or 16:9.

4. Zoom: Increase zoom when you need more precise control.

5. Rotate / Flip: Optionally rotate or flip the image before exporting.

6. Output Size: Enter width and/or height if you want a specific output dimension.

7. Download: Choose JPG, PNG or WEBP and click Crop & Download.

Helpful Tips

Get better crops.

Tip 1: Use 1:1 when you need a square image.

Tip 2: Use 16:9 for wide thumbnails and video-style images.

Tip 3: Use 9:16 for vertical content.

Tip 4: Keep the important subject inside the selected area.

Tip 5: Leave output dimensions empty if you want the natural crop size.

FAQ

Common questions.

Can I crop freely?
Yes. Select Free.

Can I create a square image?
Yes. Select 1:1.

Can I rotate while cropping?
Yes. Use the Rotation option.

Can I set exact output dimensions?
Yes. Enter the desired width and height.

Does the original image change?
No. A new cropped file is created.

Are my images uploaded?
No server upload is required.
