Helpful Tips

Get better results.

Tip 1: Start with 2× when the original image is already reasonably large.

Tip 2: Use 4× for small images when you need a much larger output.

Tip 3: Avoid excessive sharpness because it can create visible edges.

Tip 4: PNG is useful when preserving image quality is important.

FAQ

Common questions.

What does 2× mean?
The width and height are each doubled, producing 4× as many pixels.

What does 4× mean?
The width and height are each multiplied by four.

Is this a true AI model?
This standalone browser version uses high-quality image interpolation and sharpening; it does not download or run a large neural-network model.

Does the original change?
No. A new enlarged image is created.

Are images uploaded?
No server upload is required.
